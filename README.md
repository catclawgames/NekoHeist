# Neko Heist

Lead a crew of cat burglars through trap-filled Japanese manors, steal the treasure, and build a base other players will try to rob.

**Play:** https://catclawgames.github.io/NekoHeist/

This repo is the website build: `index.html` is the whole game. Online play (accounts, raids, leaderboard) is enabled by putting Firebase settings in `firebase-config.js`; without them the game runs offline against computer manors.
